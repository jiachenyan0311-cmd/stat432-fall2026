# STAT 432 Plot Formatting

- Preserve the original data, calculations, and statistical meaning.
- Make important trends and differences visually clear without exaggerating them.
- Use sufficient margins so titles, axis labels, tick labels, and legends are not clipped.
- Use a short and informative title.
- Use clear axis labels and readable tick labels.
- Use high-contrast, distinguishable colors for multiple curves, and avoid colors that are too similar.
- Use different point shapes or line types when multiple curves appear in the same plot.
- Use thicker lines and appropriately sized points so important details are easy to see.
- Use readable font sizes for titles, axes, and legends.
- Keep the figure size balanced and avoid unnecessary visual clutter.
- Apply these rules to existing R or Python plotting code without changing the underlying analysis.
